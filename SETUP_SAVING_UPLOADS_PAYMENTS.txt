YOUR PARENT PLAN: TURNING ON SAVING, UPLOADS AND PAYMENTS

Do these steps in order. Steps 1 and 2 make saving, uploads, family sharing and password resets work.
Steps 3 to 7 turn on payments. Until payments are set up, everything else
still works; the "Choose monthly / annual" buttons will just show an error.

Do NOT change supabase-config.js. It is already set up.


STEP 1. Run the new database setup (about 1 minute)
---------------------------------------------------
Supabase > your project > SQL Editor > New query.
Paste the whole of supabase-app-data-setup.sql and click Run.
(supabase-paid-vault-setup.sql must have been run before; it was.)

This creates:
- plan_data: what people type on My Plan, Essentials, Money and Care
- documents + a private "documents" storage bucket: Scan & Organize uploads
  (free accounts: 10 documents; Plus: unlimited; 15 MB per file)
- billing columns on memberships, filled in by Stripe

Each account can only see its own rows and files.

Then open another New query, paste the whole of supabase-family-setup.sql
and click Run. This adds family sharing (invitations, editors and viewers),
the Free limit of 2 Care facilities, and opens shared plans and documents
to the family members each owner has invited. The Password Vault stays
private to each person.


STEP 2. Tell Supabase your website address
------------------------------------------
Supabase > Authentication > URL Configuration:
- Site URL: your live address, e.g. https://www.yourparentplan.com
- Redirect URLs: add  https://www.yourparentplan.com/**
This makes the "confirm your email", "reset your password" and "change
email" links bring people back to your site (and straight to checkout or
to a family invitation if that's where they were headed).


STEP 3. Create the Plus product in Stripe
-----------------------------------------
Start in TEST MODE (toggle at the top of the Stripe dashboard).
Stripe > Product catalog > Add product:
- Name: Your Parent Plan Plus
- Price 1: $4.99, Recurring, Monthly
- Price 2: $39.99, Recurring, Yearly
Open each price and copy its ID (starts with price_...).

Stripe > Settings > Billing > Customer portal:
- Turn on: update payment method, cancel subscriptions (at end of period),
  and switch plans (add both Plus prices).
- Save.


STEP 4. Install the Supabase command-line tool (one time)
---------------------------------------------------------
On your computer, in a terminal:
  npm install -g supabase        (or on a Mac: brew install supabase/tap/supabase)
  supabase login
Then, in the folder where this repository is downloaded:
  supabase link --project-ref hlsnebikonnflddsunuj


STEP 5. Save the secret keys on Supabase (never in the website files)
---------------------------------------------------------------------
Stripe > Developers > API keys > Secret key (sk_test_...).

  supabase secrets set STRIPE_SECRET_KEY=sk_test_...
  supabase secrets set STRIPE_PRICE_PLUS_MONTHLY=price_...
  supabase secrets set STRIPE_PRICE_PLUS_ANNUAL=price_...
  supabase secrets set SITE_URL=https://www.yourparentplan.com

SITE_URL must be exactly the address people use, with no slash at the end.
If the site also opens at a second address (for example without "www"),
add it too:
  supabase secrets set EXTRA_ALLOWED_ORIGINS=https://yourparentplan.com


STEP 6. Deploy the four functions
------------------------------------------
  supabase functions deploy create-checkout
  supabase functions deploy billing-portal
  supabase functions deploy stripe-webhook --no-verify-jwt
  supabase functions deploy delete-account

(delete-account powers "Delete my account" on the Account & family page.
It cancels the person's subscription, removes their files and deletes them.)

(--no-verify-jwt is only for the webhook: Stripe can't log in to Supabase,
so that function checks Stripe's signature instead.)


STEP 7. Point Stripe at the webhook
-----------------------------------
Stripe > Developers > Webhooks > Add endpoint:
- URL: https://hlsnebikonnflddsunuj.supabase.co/functions/v1/stripe-webhook
- Events:
    checkout.session.completed
    customer.subscription.created
    customer.subscription.updated
    customer.subscription.deleted
    customer.subscription.paused
    customer.subscription.resumed
Save, then click "Reveal" under Signing secret (whsec_...) and run:
  supabase secrets set STRIPE_WEBHOOK_SECRET=whsec_...


TEST IT
-------
1. Sign up with a new email on your live site and confirm it.
2. Pricing > Choose monthly. Pay with the test card 4242 4242 4242 4242,
   any future date, any CVC, any ZIP.
3. You land on My Plan with "Welcome to Plus". The Password Vault and
   unlimited uploads are unlocked.
4. Pricing > Manage billing > cancel. Plus stays on until the end of the
   paid period, then switches back to Free automatically.
If step 3 says "still being switched on" for more than a minute, open
Stripe > Webhooks > your endpoint and look for failed deliveries, and
Supabase > Edge Functions > stripe-webhook > Logs.

GOING LIVE
----------
Switch Stripe to live mode, create the same product and two prices there,
create a live webhook (step 7 again), and re-run step 5 and the
STRIPE_WEBHOOK_SECRET command with the live keys and price IDs.


WHAT HAPPENS TO DATA PEOPLE ALREADY ENTERED
-------------------------------------------
Earlier versions kept the checklist and Care facilities in the browser only.
The first time someone signs in on that same browser, it is copied into
their account automatically and removed from the browser.
Essentials, Money and the parent's name were never saved before, so there is
nothing to move.
